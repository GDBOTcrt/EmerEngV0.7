# EmerEngV0.6
RubyDung but if it was never Abandoned :)

Okay, little TL;DR about the lore, The game is RubyDung, Clearly, But thing is, its UNDERCOVER, EmerEng is still on 2010, after 2009, a disaster happened and Microsoft buyed a project called "MineCraft" from a random dude, the Random Dude stole a USB drive from a 16 year old going home, Where he was making a cool game that was actually RubyDung in secret, then minecraft grew and grew, but the 16 year old's project was still stolen, then days later, they found the guy with a copy of the code, and sent it to the sixteen year old, the sixteen year old continued it, not knowing what MineCraft even was, ignoring it and for some reason adding things that were Similar, but not quite, never inspiring himself about it, but having them, he felt like he should do something and actually backlash them, making his game even more like the copy of his game. But making it even more different, and Creative based, No players yet, but he felt calm that he atleast has a cool game nobody has discovered again, and he has trust that he can achieve more users seeing his little project.

WOW, i achieved a flow state while doing this, sick story though.

To run it, You need a Python IDE, and python 3.13 or up, if it works with Panda3d and Ursina, Of course.

it also Features: 
* Block placing n breaking
* Trees when pressing "T"
* Resets and tps you to a random place when pressing "R"
* You can Play it

Its Open-Source, use it for your liking!, it sucks but.. it works :)
